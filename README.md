# Chan Myae Kyaw Min — Portfolio

A responsive, single-page portfolio for a backend-focused developer. The site uses a dark retrofuturist visual style and is built with plain HTML and CSS.

## View locally

Open `index.html` in a browser. To serve it locally instead, run:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project files

* `index.html` — portfolio page, styling, and content.
* `my-cat.webp` — cat photo used in the hobbies section.
* `plan.md` — current page and content plan.

## Personalize

Update project summaries and repository links in `index.html` with your own project details. Certificate links, email, and GitHub profile are in the Skills & Certifications and Contact sections. Replace `my-cat.webp` if you want to use a different photo.
